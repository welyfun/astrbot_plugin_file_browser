# Web 文件浏览器 🔭

AstrBot 插件 —— 在 Dashboard 中浏览和管理文件。

## 功能

-  **浏览** — 点击文件夹进入，面包屑导航快速跳转
-  **下载** — 点击文件名或下载按钮
-  **上传** — 选择文件上传到当前目录
-  **删除** — 删除文件或空文件夹（带确认弹窗）

## 配置

在 WebUI 插件管理中可修改 **共享文件夹路径**：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `shared_path` | string | `data/workspaces` | 支持相对路径（相对于 `data/`）和绝对路径 |

## 安全

- 路径穿越防护（无法访问共享目录外的文件）
- 隐藏文件不可见（`.` 开头）
- 仅空目录可删除
- 根目录不可删除

## 安装

1. WebUI → 插件管理 → 上传插件
2. 点击插件卡片 → 进入「file-browser」Page
